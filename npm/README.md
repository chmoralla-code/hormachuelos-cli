# HORMACHUELOS

Your AI coding sidekick, in the terminal.

```
npm install -g hormachuelos
```

Then run `hormachuelos` (or `horma`) in any folder. It works the same from cmd, PowerShell, Windows Terminal, bash, zsh and fish, on:

- Windows 10 and 11 (x64, Arm64)
- macOS (Apple Silicon and Intel)
- Linux (x64, Arm64)

Try it without installing: `npx hormachuelos`.

The install downloads the build for your computer from hormachuelos.vercel.app and checks its signature before keeping it. If the download is skipped (offline, or `--ignore-scripts`), it happens the first time you run `hormachuelos`. Inside the app, `/update` keeps it current.

Sign in with `/login`, or set `HORMACHUELOS_API_KEY`.

Uninstall: `npm uninstall -g hormachuelos`.
